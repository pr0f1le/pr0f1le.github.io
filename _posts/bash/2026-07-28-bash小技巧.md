## 单词拆分

单词拆分是 bash 中很重要也很容易踩坑的地方，简单来说，就是 bash 会将变量中的单词进行拆分，在
使用变量的时候让其中的几个单词作为单独的参数被传入函数或命令。

举个例子

```bash
str="a b c"
args_count_and_print() {
    echo "args count: $#"
    echo "args: $@"
}
args_count_and_print $str

# 输出
args count: 3
args: a b c
```

可以看到，我们虽然只传递了一个参数 `$str` 但是函数得到的是 3 个参数，这就是单词拆分。

除了空格，默认情况下换行和制表符也会被认为是单词拆分的分隔符。

```bash
str_n=$(printf "a\nb\nc")
str_t=$(printf "a\tb\tc")
args_count_and_print() {
    echo "args count: $#"
    echo "args: $@"
}
echo "origin fomat:"
echo "$str_n"
echo ""
echo "$str_t"
echo ""
echo "word split:"
args_count_and_print $str_t
args_count_and_print $str_n

# 输出
origin fomat:
a
b
c

a	b	c

word split:
args count: 3
args: a b c
args count: 3
args: a b c

```

可以看到单词拆分的效果。

### IFS

在上一个例子之前我们讲这是默认情况，非默认情况就要由 `IFS` (Internal Field Separator)
提供分隔符。

再举个栗子 🌰

```bash
str="a,b,c"
show_args() {
    echo "args count: $#"
    echo "args: $@"
}

show_args $str
IFS=','
show_args $str

# 输出
args count: 1
args: a,b,c
args count: 3
args: a b c
```

可以看到拆分的效果在设置 `IFS` 之后的变化

### 不拆分

如果我们不希望拆分该怎么办呢？

🌰如，我们希望查找三个单词的组合 `i am rich` 

```bash
str="i am sorry
i am rich
you and i
you are rich"

pat="i am rich"

grep $pat <<< "$str"

# 输出
grep: am: 没有那个文件或目录
grep: rich: 没有那个文件或目录
```

很可惜，出错了

最简单的办法就是将参数用引号括起来(使用双引号，否则变量不替换)

```bash
str="i am sorry
i am rich
you and i
you are rich"

pat="i am rich"

grep "$pat" <<< "$str"

# 输出
i am rich
```

这就找到了。

我们现在知道如何避免拆分了，但是我们并不清除它到底在什么时候会拆分，什么时候不会，
哪里需要双引号，哪里不需要。

### 拆分规则

其实最绝对的一条规则我们已经找到了：**双引号内的不拆**。因此，只要不确定它拆不拆
，如果不希望拆，加双引号就没问题。

拆的规则有这些:

- 变量展开/参数展开 `$var`
- 命令替换 `$(cmd)` 或 ``cmd``
- 算数展开 `$(( expr ))`

不拆的规则:

- 赋值 `var=$smth`
- 双引号 `printf "%s" "$var"`

接下来有几个拆分的小🌰

```bash
args_count() {
    echo "args count: $#"
    echo "args: $@"
}

str="a b c"
args_count $str
args_count "$str"

IFS='-'
args_count $(date +%F)
args_count "$(date +%F)"

IFS='0'
args_count $(( 1234 * 100000 + 5678 ))
args_count "$(( 1234 * 100000 + 5678 ))"
unset IFS

# 输出
args count: 3
args: a b c
args count: 1
args: a b c
args count: 3
args: 2026 07 28
args count: 1
args: 2026-07-28
args count: 2
args: 1234 5678
args count: 1
args: 123405678
```

肥肠简单

## 展开

前面我们提到了变量展开/参数展开等，它是 bash 展开中的一种

bash 大致有这些展开

| 类型       | 写法         | 结果       |
|------------|--------------|------------|
| 变量展开   | $var         | hello      |
| 命令替换   | $(date +%F)  | 2026-07-28 |
| 算数展开   | $(( 1 + 2 )) | 3          |
| `~` 展开   | ~            | /home/xxx  |
| 大括号展开 | {1..3}       | 1 2 3      |

`~` 展开和大括号展开在其他三个展开之前完成，而在展开完成之后，bash 将进行
[单词拆分](#单词拆分)

## 路径扩展

在经过了单词拆分之后，bash 还有一个默认行为是路径扩展。

它的意思是在经过前面几步处理的结果中寻找 `*`、`?`、`[]` 这些字符，并替换为文件名

一个🌰

```bash
files="test/*.log"
args_count() {
    echo "args count: $#"
    echo "args: $@"
}
args_count $files

# 输出
args count: 5
args: test/1.log test/2.log test/3.log test/4.log test/5.log
```

这里 `*` 就被替换为了文件名

如果没有匹配成功，就原样输出

```bash
args_count $files

# 输出
args count: 1
args: test/*.log
```

在某些时候，这可能造成安全问题，为了关闭它，最简单的当然还是用引号括起来，
或者在脚本里，使用 `set -f` 关闭脚本里的路径扩展。

```bash
set -f

files="test/*.log"
args_count() {
    echo "args count: $#"
    echo "args: $@"
}
args_count $files

# 输出
args count: 1
args: test/*.log
```
