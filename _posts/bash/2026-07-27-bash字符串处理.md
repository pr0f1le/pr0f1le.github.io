bash 脚本中经常需要进行字符串处理，例如从路径中取文件名需要使用 `basename`，
对字符串进行替换需要使用 `sed` 等

此外还有 `awk`，`cut`，`tr` 等进行提取和转换的工具

但是使用这些工具都需要创建新的子进程，如果重复运行很多次，或者脚本中有很多外部工具的调用，
都会导致大量时间的浪费

明明只是一些非常简单的功能，像是去除固定前缀后缀，提取某一行字符串的某一节或某几个字符等
等，这种使用 C 语言都只需要一个循环加一些判断，用不到几百个 CPU 时钟周期的功能，如果调用
外部工具还需要加载共享库，打开管道或文件描述符等各种系统调用，实在是不划算

幸运的是，bash 中有办法直接进行简单的字符串处理

### bash 内置字符串处理方法
    
我们以 `str=/path/to/hello_world.c` 为例

| 操作类型 | 语法              | 示例                      | 输出                     |
|----------|-------------------|---------------------------|--------------------------|
| 获取长度 | `${#str}`         | `echo ${#str}`            | `22`                     |
| 获取子串 | `${str:st:len}`   | `echo ${str:9:5}`         | `hello`                  |
| 首个替换 | `${str/old/new}`  | `echo ${str/o/a}`         | `/path/ta/hello_world.c` |
| 全部替换 | `${str//old/new}` | `echo ${str//o/a}`        | `/path/ta/hella_warld.c` |
| 开头替换 | `${str/#old/new}` | `echo ${str/#\/path/foo}` | `foo/to/hello_world.c`   |
| 结尾替换 | `${str/%old/new}` | `echo ${str/%.c/.o}`      | `/path/to/hello_world.o` |
| 最短掐头 | `${str#pat}`      | `echo ${str#*/}`          | `path/to/hello_world.c`  |
| 最长掐头 | `${str##pat}`     | `echo ${str##*/}`         | `hello_world.c`          |
| 最短去尾 | `${str%pat}`      | `echo ${str%.*}`          | `/path/to/hello_world`   |
| 最长去尾 | `${str%%pat}`     | `echo ${str%%l*}`         | `/path/to/he`            |
| 转大写   | `${str^^}`        | `echo ${str^^}`           | `/PATH/TO/HELLO_WORLD.C` |
| 转小写   | `${str,,}`        | `echo ${str,,}`           | `/path/to/hello_world.c` |

### 简单正则匹配

`[[ ... ]]` 中可以使用 `=~` 进行正则匹配

```bash
str=hello-2026-world.txt
if [[ "$str" =~ ^hello-[0-9]+-.*\.txt$ ]]; then
  echo "yes"
fi
```
输出 `yes`

### 字符串转数组

将字符串拆成数组可以使用 `read` + `IFS`

```bash
str='apple,orange,pear'
IFS=',' read -r -a arr <<< "$str"
echo ${arr[1]}
```
输出 `orange`

在不指定 `IFS` 的情况下，默认使用空格和制表符作为 `read` 的分隔符
