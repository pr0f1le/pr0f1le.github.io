## 规则变量

| 变量 | 用法                                                            |
|------|-----------------------------------------------------------------|
| `$@` | 代表当前规则所要生成的目标文件的完整名称                        |
| `$^` | 代表规则中所有依赖文件的名称，去除重复并以空格分隔              |
| `$+` | 功能与 `$^` 类似，但保留了依赖文件中重复出现的部分              |
| `$*` | 代表目标模式中 `%` 匹配的部分                                   |
| `$<` | 代表规则中第一个依赖文件的名称                                  |
| `$?` | 代表所有比目标文件新的依赖文件列表,常用于只增量更新静态库等场景 |

## 预设变量

### 常用程序变量名

| 变量  | 默认值     | 说明           |
|-------|------------|----------------|
| `CC`  | `cc`       | C 编译器       |
| `CXX` | `g++`      | C++ 编译器     |
| `CPP` | `$(CC) -E` | C 预处理器     |
| `AS`  | `as`       | 汇编器         |
| `AR`  | `ar`       | 归档管理程序   |
| `FC`  | `f77`      | Fortran 编译器 |
| `RM`  | `rm -f`    | rm             |

### 常用隐含规则

| 规则         | 命令                                        |
|--------------|---------------------------------------------|
| `%.o: %.c`   | `$(COMPILE.c) $(OUTPUT_OPTION) $<`          |
| `%.o: %.cpp` | `$(COMPILE.cpp) $(OUTPUT_OPTION) $<`        |
| `%: %.o`     | `$(LINK.o) $^ $(LOADLIBES) $(LDLIBS) -o $@` |

### 常用命令和参数变量

| 变量          | 值                                                 |
|---------------|----------------------------------------------------|
| `COMPILE.c`   | `$(CC) $(CFLAGS) $(CPPFLAGS) $(TARGET_ARCH) -c`    |
| `COMPILE.cc`  | `$(CXX) $(CXXFLAGS) $(CPPFLAGS) $(TARGET_ARCH) -c` |
| `COMPILE.C`   | `$(COMPILE.cc)`                                    |
| `COMPILE.cpp` | `$(COMPILE.cc)`                                    |
| `LINK.o`      | `$(CC) $(LDFLAGS) $(TARGET_ARCH)`                  |
| `CFLAGS`      | 空                                                 |
| `CPPFLAGS`    | 空                                                 |
| `LDFLAGS`     | 空                                                 |

`CFLAGS`, `CPPFLAGS`, `LDFLAGS` 等为空，但是只需要在 `Makefile`{: .filepath} 中设置这些变量
就可以起到书写规则的作用

> 对不同版本的 `make` 可能有些许变化，在空目录中使用 `make -p` 查看
{: .prompt-tip} 

## 变量定义

### `=` 递归展开赋值

使用时才展开并赋值

```makefile
A = $(B)
B = hello
all:
    echo $(A) # 此时 A 被使用，展开并赋值，输出 hello
```

如果 `A = $(B)`，`B = $(A)` 容易导致无限递归

### `:=` 直接赋值

最常用的赋值方式

```makefile
B = foo
A = $(B) # 直接展开并赋值
B = hello
all:
    echo $(A) # 输出 foo
```

### `?=` 条件赋值

未定义时的默认值

```makefile
A ?= hi
all:
    echo $(A)
```

如果使用 `make` 则输出 A 的默认值 hi，如果使用 `make A=hello` 则输出 hello

### `!=` Shell 命令赋值

```makefile
SRC != ls *.c
# 等价于 SRC = $(shell ls *.c)
all:
    echo $(SRC)
```

使用 Shell 命令为变量赋值，获取 `pkg-config --cflags --libs` 等很方便

### `+=` 追加赋值

```makefile
SRC := main.c
SRC += utils.c
CFLAGS += -Wall -g
all:
    echo $(SRC) $(CFLAGS)
```

给变量追加值
